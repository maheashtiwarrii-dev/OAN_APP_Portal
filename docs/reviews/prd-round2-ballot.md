# PRD Review — Round 2 Ballot (2-of-3 rule)

Round 1 produced 36 proposals (A = Business/Product, B = Security/Privacy, C = APEX Architect). Overlaps are merged below into 31 ballot items. Where reviewers conflicted, the item offers options (vote for one option, or REJECT).
**Rule:** an item (or option) is applied to the PRD only if at least 2 of the 3 reviewers vote AGREE.
Decisions Q1–Q21 in `01-requirements-review.md` are final and are not on the ballot.
