Summary

The project started on 12 October 2026 (sprint S0, 12–23 October). The build waves W0 to W7 run on the dev environment and every page is ready for user acceptance testing. On 17 October the AI assistant was built after the privacy impact assessment was approved (page 48 "Ask OAN"; Q41), a volunteering capability was added for city-wise social causes (pages 79 and 791; Q42), and sign-up no longer needs e-mail: anyone can create an account with any address, Gmail included, and continue straight to the membership application (Q40). The environment workstream WS0 is complete. A catalogue of all 96 APEX pages is published as a PDF.
