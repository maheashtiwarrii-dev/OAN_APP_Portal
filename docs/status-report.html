OAN Portal (Oracle Alumni Network)

Oracle APEX application 200 on Autonomous Database · Plan v3.2 · APEX Build Pack v1.1 · development environment only

Summary

The project started on 12 October 2026 (sprint S0, 12–23 October). All build waves W0 to W7 already run on the dev environment and are ready for user acceptance testing, well ahead of the sprint calendar, which runs to 21 May 2027. Members can use profiles, the directory and CVs, insights and events, conversations, opportunities, referrals and the helpdesk, groups, experts, mentoring, training, chapters and initiatives. Companies can register, post opportunities and needs, and review responses. Administrators have a dashboard, aggregate reports, settings and job monitoring. Every change is validated, tested on the database and pushed to GitHub, where CI runs on each push.

Not yetready for go-live: ready for user acceptance testing on dev

Go-live position: the application is feature-complete for v1 and ready for user acceptance testing with synthetic data, including the admin and moderation pages (dev-only test roles, decision Q36). Two defects found while confirming readiness were fixed on 16 October: public pages such as Create account and Register your company returned an error to signed-out visitors, and staff roles could not take effect because the app had no access-control roles. Go-live needs the 18-point gate 8.0: a production environment on APEX 26.2, staff sign-in through an identity provider with 2-step verification in production (Q33), email delivery (0.7), security, load and accessibility tests, the DPIA and legal texts, named owners and a signed UAT.
