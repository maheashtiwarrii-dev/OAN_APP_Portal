OAN Portal (Oracle Alumni Network)

Oracle APEX application 200 on Autonomous Database · Plan v3.2 · APEX Build Pack v1.1 · development environment only

Summary

The portal is well ahead of plan. Sprint S0 formally starts on 19 October, yet the database platform and waves W0 to W5 already run on the dev environment: sign-in and onboarding, the member shell and Home, profiles, directory and CV, insights and events, conversations and notifications, opportunities, referrals, helpdesk and skills in demand, plus company registration for partners and other employers. Every change is validated, tested on the database and pushed to GitHub, where CI runs on each push.
